## 浏览器实际流程

使用内置 Chromium 浏览器，本次服务端口后端8011、前端3011。默认8000被其他进程占用，本次没有结束该进程。访问 `http://127.0.0.1:3011/sales`。

1. user 登录，查看三笔模拟数码订单、价格、签收时间、物流状态。
2. DEMO-1001 关联咨询“退货政策和运费由谁承担？”：本地回答显示退换政策v1和运费政策v1。
3. 确认表单提交退货原因，生成 **AS-8d7530ba68c3**，买家显示待人工审核。
4. admin 登录，填写意见并受理；user 再登录，看到“已受理”和同一处理意见。
5. admin 将该工单记录为处理完成，明确写明模拟处理不代表实际退款到账。
6. admin 编辑运费政策加入包装说明，保存v2；版本历史可查看v1/v2，审计记录包含创建、受理、完成、政策更新。
7. 实际停止并重新启动售后后端。买家重新登录打开原历史会话，旧消息、关联订单和已完成工单仍存在。
8. 原会话询问“我的申请进度以及最新运费政策？”：返回 completed 和商家完成意见，并引用运费政策v2和新增包装说明。
9. 打开工单政策快照：运费仍为v1，无新增包装文字，验证历史依据未被覆盖。
10. 刷新页面恢复登录；最终在我的申请中看到处理完成。
